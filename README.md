## 🧪 Experiments

### Experiment 1 – Data Preprocessing

Performed preprocessing on the **Employee Dataset**, including:

- Handling missing values
- Removing duplicate records
- Outlier detection
- Data encoding
- Normalization
- Standardization

### Experiment 2 – Exploratory Data Analysis

Performed EDA on the **Titanic Dataset** using:

- Statistical analysis
- Data visualization
- Missing value analysis
- Correlation analysis

### Experiment 3 – Linear & Logistic Regression

Implemented:

- **Linear Regression** using the USA Housing Dataset
- **Logistic Regression** using the Diabetes Dataset

### Experiment 4 – Principal Component Analysis

Applied **PCA** on the Iris Dataset for:

- Dimensionality reduction
- Data standardization
- Feature transformation
- Data visualization

### Experiment 5 – Support Vector Machine (SVM) for Classification

Implemented **Support Vector Machine (SVM)** for classification using the **Iris Dataset**.

The experiment covers:

- Hyperplane
- Support vectors
- Maximum margin
- Linear SVM
- Non-linear SVM
- Kernel functions
- RBF kernel
- Feature scaling
- Classification accuracy
- Confusion matrix
- Classification report

### Experiment 6 – Decision Tree & K-Nearest Neighbour (KNN)

Implemented and compared:

- **Decision Tree Classifier**
- **K-Nearest Neighbour (KNN)**

using the **Iris Dataset**.

The experiment covers:

- Decision tree splitting
- Entropy
- Information Gain
- Gini Index
- KNN
- Euclidean distance
- Manhattan distance
- Feature scaling
- Accuracy
- Confusion Matrix
- Classification Report

**Output:**

```text
Model Comparison
-------------------------
Decision Tree Accuracy: 100.0 %
KNN Accuracy: 100.0 %
```

### Experiment 7 – Comparison of Different Regression Algorithms

Compared multiple regression algorithms for predictive modeling using the **California Housing Dataset**.

Algorithms implemented:

- **Linear Regression**
- **Polynomial Regression**
- **Decision Tree Regression**
- **Random Forest Regression**
- **Support Vector Regression (SVR)**

Performance was evaluated using:

- MAE
- MSE
- R² Score

**Output:**

```text
Model Comparison
-----------------------------
Linear Regression -> MAE: 0.5332 | MSE: 0.5559 | R2: 0.5758
Polynomial Regression -> MAE: 0.467 | MSE: 0.4643 | R2: 0.6457
Decision Tree -> MAE: 0.4547 | MSE: 0.4952 | R2: 0.6221
Random Forest -> MAE: 0.3275 | MSE: 0.2554 | R2: 0.8051
SVR -> MAE: 0.3973 | MSE: 0.3542 | R2: 0.7297
```
