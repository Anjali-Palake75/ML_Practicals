# Machine Learning Practical Experiments

This repository contains practical implementations of **Machine Learning and Data Science concepts using Python**.

## 📚 Experiments Included

| No. | Experiment | Dataset |
|---|---|---|
| 1 | Data Preprocessing | Employee Dataset |
| 2 | Exploratory Data Analysis (EDA) | Titanic Dataset |
| 3 | Linear & Logistic Regression | USA Housing & Diabetes Dataset |
| 4 | Principal Component Analysis (PCA) | Iris Dataset |

## 🛠️ Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## 🧪 Experiments

### Experiment 1 – Data Preprocessing

Performed preprocessing on the **Employee Dataset**, including:

- Handling missing values
- Removing duplicate records
- Outlier detection
- Data encoding
- Normalization
- Standardization

### Experiment 2 – Exploratory Data Analysis

Performed EDA on the **Titanic Dataset** using:

- Statistical analysis
- Data visualization
- Missing value analysis
- Correlation analysis

### Experiment 3 – Linear & Logistic Regression

Implemented:

- **Linear Regression** using the USA Housing Dataset
- **Logistic Regression** using the Diabetes Dataset

### Experiment 4 – Principal Component Analysis

Applied **PCA** on the Iris Dataset for:

- Dimensionality reduction
- Data standardization
- Feature transformation
- Data visualization

## 🎯 Learning Outcomes

Through these experiments, the following concepts are practiced:

- Data preprocessing and cleaning
- Exploratory Data Analysis
- Data visualization
- Regression algorithms
- Classification
- Dimensionality reduction
- Machine Learning model evaluation
